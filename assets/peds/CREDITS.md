# Pedestrian sprites

The people drawn in the game come from layers of the Universal LPC Spritesheet Character Generator with our own painted additions: see `lpc/CREDITS.md` and `lpc/LICENSE.md`.
The generated renderer in this folder (`raster.js`, `model.js`, `people.js`, `atlas.js`, `sprites.js`) is original code with no third-party art; `sprites.js` is still the cast (who exists, weights, outfits), `model.js` still draws the Garage driver preview and the `?pedgen` fallback.
