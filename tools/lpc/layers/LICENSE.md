# tools/lpc/layers

Image layers downloaded from the Universal LPC Spritesheet Character Generator (commit 86160e7, https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator) by `tools/lpc/lib.mjs`.
Same terms as `assets/peds/lpc/`: see `assets/peds/lpc/CREDITS.md` for the authors, licences and links of every layer, and `assets/peds/lpc/LICENSE.md` for how they are treated.
These files are build inputs only: the game loads `assets/peds/lpc/atlas.png`, not these.
